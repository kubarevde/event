# Лендинг мероприятия с админкой

Next.js 15 + Tailwind. Тексты, картинки, форма заявки и статистика управляются из админки — код трогать не нужно.

## Что есть в админке (`/admin`)

| Раздел | Что делает |
|---|---|
| **Статистика** | Посетители, визиты, просмотры, заявки и конверсия за период; графики по дням; воронка (визит → клик «Подать заявку» → дошли до формы → начали заполнять → отправили); источники переходов, UTM-метки, устройства, браузеры, активность по часам. Кнопка «Отчёт CSV». |
| **Заявки** | Таблица заявок с фильтрами по форме, статусу и периоду, статусы (новая / в работе / подтверждена / оплачена / отклонена), комментарий менеджера, выгрузка в CSV (открывается в Excel). |
| **Формы** | Конструктор форм: поля «строка», «текст», email, телефон, число, выпадающий список, радио, несколько вариантов, галочка, согласие на обработку ПДн. Обязательность, порядок, ширина, подсказки, живой предпросмотр. |
| **Контент сайта** | Все тексты всех блоков, дата и место, цена, логотип и фирменные цвета, спикеры с фото, FAQ, меню, подвал, SEO. Любой блок можно скрыть. |

Статистика собирается самим сайтом (без Яндекс.Метрики и внешних счётчиков): боты и залогиненный администратор не учитываются.
Защита формы от спама: скрытое поле-ловушка, проверка скорости заполнения и лимит заявок с одного IP.

## Запуск

```bash
cp .env.local.example .env.local   # задайте ADMIN_PASSWORD
npm install
npm run dev                        # http://localhost:3000, админка — /admin
```

Продакшен:

```bash
npm run build
npm start                          # порт 3000, PORT=... чтобы сменить
```

При первом запуске создаются база `storage/site.db` с текущим контентом и форма заявки по умолчанию.

## Деплой

Нужен сервер с Node.js 20+ (VPS, Docker и т.п.). Статический хостинг и Vercel не подойдут:
данные хранятся в SQLite-файле на диске.

- Папку `storage/` (или `DATA_DIR`) **сохраняйте между деплоями и бэкапьте** — там база с контентом, заявками, статистикой и загруженные картинки.
- Сайт должен работать по https (иначе задайте `INSECURE_COOKIES=1`).
- За nginx передавайте `X-Forwarded-For`, чтобы лимиты по IP работали корректно.

## Как сделать новый сайт на этой основе

1. Скопируйте репозиторий, задайте `ADMIN_PASSWORD`, запустите.
2. В админке «Контент сайта» замените тексты, логотип, цвета, дату и место.
3. В «Формы» настройте поля заявки.

## Структура

- `app/page.tsx` — лендинг, читает контент из базы
- `app/admin/*` — админка; `middleware.ts` закрывает её паролем
- `app/api/*` — приём заявок, трекинг, API админки
- `lib/content.ts` — модель контента и значения по умолчанию
- `lib/content-schema.ts` — какие поля показывает редактор контента
- `lib/forms.ts` — модель формы и проверка ответов
- `lib/analytics.ts` — сбор и отчёты статистики
